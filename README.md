# Number Guessing Game in Java 

## Description
A simple interactive Java game in which the computer generates a random number between 1 and 100, and the user tries to guess it.

## Features
- Generates a random number.
- Provides higher and lower hints.
- Counts the number of attempts.
- Handles invalid input.

## Concepts Used
- Java `Scanner`
- `Random` class
- Loops and conditional statements
- Input validation

## How to Run
1. Install the Java JDK.
2. Save the code as `NumberGuessingGame.java`.
3. Open a terminal in the file's directory.
4. Compile and run:

```bash
javac NumberGuessingGame.java
java NumberGuessingGame
```
